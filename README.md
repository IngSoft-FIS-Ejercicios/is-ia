# Prácticos IA

Material didáctico para la enseñanza de herramientas de Inteligencia Artificial (IA) aplicadas a la Ingeniería de Software, elaborado en el contexto de la asignatura Fundamentos de Ingeniería de Software (FIS) de la Universidad ORT Uruguay.

El material combina los contenidos propios de la asignatura (codificación, interfaz de usuario y testing) con el uso de agentes de codificación, poniendo el foco en la supervisión y validación de los resultados generados (enfoque human-in-the-loop).

## Requisitos

- Visual Studio Code (o un IDE compatible) con GitHub Copilot u otra herramienta de IA equivalente.
- Navegador web.
- Node.js 18 o superior (prácticos de Interfaz de Usuario, Testing e Integrador).

Las instrucciones de instalación y ejecución de cada práctico se encuentran en su README.
